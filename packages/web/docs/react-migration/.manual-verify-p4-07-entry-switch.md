## 1. lang 우선순위 4종 매트릭스 (FOUC/lang 인라인 — index.html:14-39 보존분)

우선순위: **URL `?lang=` → localStorage `spyglass:lang` → navigator.language → 기본 'ko'**.

## 8. SPA fallback (★서버 패키지 — 본 worktree 미적용, 별도 처리)

P1-02 §5-2 결정: React Router 직접진입/새로고침(`/meta-docs`, `/settings`) 시 데몬이 404 대신 `index.html` 반환해야 한다.
현재 `dispatch.ts` 는 `/`·`/assets/`·`/locales/`·favicon 만 매칭하고 미매칭은 404(`dispatch.ts` 404 블록).

**미적용 사유**: dispatch.ts 는 `packages/server`(백엔드)로, P1-02 §4-1·CPL-3 가 **백엔드 변경은 web 트랙과 분리된 커밋/worktree 로 격리**(bisect 가 backend/client 회귀를 구분)하도록 명시. 본 작업은 web 진입 전환(파일만)이므로 dispatch 는 손대지 않는다.

**후속 서버 task 지시(정확한 1분기 + 1행)**:
1. `dispatch.ts` 404 블록 직전에 SPA fallback 1분기 추가:
   ```ts
   // SPA fallback (P1-02 §5-2): Accept 가 json 아닌 GET + 알려진 API/asset 접두 아님 → index.html.
   if (req.method === 'GET' && !(req.headers.get('accept') ?? '').includes('application/json')) {
     const file = webFile('/index.html');
     if (await file.exists()) {
       return new Response(file, { headers: { 'Content-Type': 'text/html; charset=utf-8' } });
     }
   }
   ```
   (api/events/collect/v1/health/assets/locales 분기는 이 지점 이전에 이미 return 하므로 잔여 GET 만 도달.)
2. `WEB_ROOT` → `dist` 전환(P1-02 §2, `dispatch.ts` fallback `'../../../web/'`→`'../../../web/dist/'`) — `dist/index.html` 산출이 `webFile('/index.html')` 와 정합(본 빌드 실측 확인).
3. mimeMap 에 `.map` 추가(P1-02 §4 — sourcemap 산출됨: `dist/assets/index-<hash>.js.map`). `js`/`css`/`svg`/`ico` 옆에 `map:'application/json'`.
4. `/locales` dist 복사(P1-02 §3 / P4-08) — WEB_ROOT→dist 시 `dist/locales/` 필요.

| SPA fallback 검증(서버 task 후) | 기대 | 통과 |
|------|------|------|
| `/meta-docs` 직접진입/새로고침 | 404 아닌 index.html 응답 → React Router 가 MetaDocsLayout 마운트 | ☐ |
| `/settings` 새로고침 | index.html 응답 → SettingsLayout | ☐ |
| `/api/dashboard` | 여전히 JSON(fallback 미적용 — Accept/접두 가드) | ☐ |
