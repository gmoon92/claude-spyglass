## 1. lang 우선순위 4종 매트릭스

| 4 | navigator `fr`(미지원) | ko | ☐ |

## 2. FOUC + classic i18n + lang-switcher

| 항목 | 기대 | 통과 |
|------|------|------|
| 초기 페인트 | `html:not(.app-ready) body{opacity:0}` → partial paint 노출 0 | ☐ |
| `.app-ready` | `window.load` 도달 시 부여 → 120ms fade-in(main.tsx 실패에도 영구 hidden 방지) | ☐ |
| `window.I18n` 선존재 | classic i18n 3종이 module 진입 앞(body-prepend)에서 로드 → React 첫 렌더 시 정의됨 | ☐ |
| lang-switcher 동작 | `#lang-switcher`(classic island) 변경 → `I18n.setLang` → reload 후 새 언어 | ☐ |

⚠️ lang-switcher 배치: 현재 `#lang-switcher` 는 React 가 소유하지 않는 classic island(body 내 `.lang-switcher-wrap`)로 존재한다.
classic lang-switcher.js 가 id 로 바인딩해 **기능은 동작**하나, 시각 배치(React Chart 헤더 편입)는 chrome 후속 부채
(P4-07 §3/§5). 본 P4-10 범위 밖 — `<select>` 4 option 은 `i18n-html-css-drift` 회귀 가드의 SoT 이기도 하여 유지한다.
