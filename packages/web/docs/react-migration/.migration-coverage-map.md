### 6-B. 잔여 3종 사유 (orphan 아님 — 의도적 보존)

`i18n.js` · `i18n-dom.js` · `lang-switcher.js` 는 ESM 모듈이 아니라 **classic `<script src>`** 로 로드되는 island 다(window.I18n 전역). 보존 근거:
