## 2. 성능 최적화 결과

- 번들: 단일 453kB → `vendor`(~267kB, i18next 포함) + `index`(~159kB, browse) + `MetaDocsLayout`(43.8kB)
  + `SettingsLayout`(38.2kB) lazy 청크. browse 초기 로드 경량화.
- 적용: RequestRow/SessionList/TurnLine/Chart 등 React.memo, nowTick→TimelineChart 격리, FlowPane/TurnSpine
  useMemo, useSessionDetail 중복 fetch 제거(onDetailData 상향), needsSessionsRefetch 처리.
- 운영 빌드: `sourcemap` 기본 off(`SPYGLASS_SOURCEMAP=1` 로 일시 on), `manualChunks` vendor 분리.
