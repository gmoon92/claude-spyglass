## D2-01 · LadybugDB native resolution 방식 — ✅ 결정: (a) NODE_PATH

**결정**: **(a) Formula wrapper `NODE_PATH` 주입**. `client.ts` 무수정.

**근거 (PoC 2026-05-31, darwin-arm64)**: `bun build --compile` standalone bin에서 `client.ts:120`과 동일한 동적 import(`import(name as string)`) 패턴으로 검증.
- `NODE_PATH` 미설정 → `error: Cannot find module '@ladybugdb/core' from '/$bunfs/root/...'` (실패)
- `NODE_PATH=<동봉 native>/node_modules` → `LOADED ok. keys: Connection,Database,PreparedStatement,QueryResult,VERSION,STORAGE_VERSION` (성공, 실제 API 노출)

**동봉 구조** (arch별):
```
share/spyglass/native/node_modules/@ladybugdb/
├── core               # wrapper (index.js + optionalDependencies)
└── core-darwin-<arch> # native lbugjs.node
```

**적용 대상**:
- `scripts/build-release-tarball.sh`: arch별 `core` + `core-darwin-<arch>`를 위 경로로 staging (D2-02).
- `tap-template/Formula/spyglass.rb` `write_env_script`: `NODE_PATH=share/spyglass/native/node_modules` 주입 + `SPYGLASS_GRAPH_MODE` `off`→`shadow` (D2-03).

**(b) 미채택**: `client.ts`를 `SPYGLASS_GRAPH_NATIVE_ROOT`에서 직접 로드 — (a)가 코드 무수정으로 동작하므로 불필요. 변경 최소화(회로차단기/lazy import 로직 보존).

**머지 주의**: `@ladybugdb/core`는 React 무관(백엔드 graph). `client.ts`·`build-release-tarball.sh`·Formula 모두 React 트랙과 충돌 없음.
