## 5. 머지 가이드 (React `feat/react-migration` 진척 반영)

React 브랜치가 `packages/web`을 **Vite 빌드(dist) + React 진입 + dist 서빙**으로 전환(P4-10)하고 `.js`→`.ts` 전수 전환(P5-01)했다. 배포 브랜치 머지 시 아래를 확인한다.

| 배포 변경 파일 | React 충돌 | 머지 시 조치 |
|----------------|:---:|------|
| `tap-template/Formula/spyglass.rb` | **없음** | 그대로 머지 |
| `scripts/build-release-tarball.sh` (web staging + native) | **중** | web staging이 `packages/web` 원본을 tar로 복사 중 → React 후엔 **Vite `dist/` 산출물을 staging하도록 경로 변경 필요**. native 동봉 부분은 무관 |
| `docs/distribution/*` | 없음 | 그대로 머지 |
| `client.ts` | — | 무수정(D2는 Formula/build만 변경) |

- **권장 순서**: React를 먼저 main 머지 → 그 위에 배포 브랜치 머지. `build-release-tarball.sh`의 web staging만 React의 `dist/` 산출 경로에 맞춰 1줄 조정(`packages/web` → `packages/web/dist` 등 React 최종 구조 기준).
- **충돌 없는 부분**(Formula·native 동봉·문서)은 그대로 통합 가능.
