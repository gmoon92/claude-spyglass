Section 1

미션 및 목표

배포를 단일 무과금 Homebrew Formula로 수렴합니다.

1. 전 의존성 번들brew install 한 번 = 런타임(Bun=SQLite)·네이티브(LadybugDB)·web·migrations·i18n 전부. 수동 설치는 훅/프록시 설정만, 라이브러리 수동 설치 0
2. 업데이트 일원화brew upgrade 하나로 앱+번들 통째 교체. git pull·Electron 업데이터 제거
3. 무과금 절대 유지ad-hoc codesign만. Apple Developer ID·notarization·Cask·DMG 금지
JVM 비유 — bun build --compile = Spring Boot executable jar. native(.node)는 JNI native처럼 arch별 분리·동봉. brew upgrade = 새 fat-jar 통째 배포(의존성은 bun.lock으로 빌드 시 resolve).

Section 6

미결 Gap (휴먼 검증 — 임의 추측 구현 금지)

  1. LadybugDB resolution(D2 핵심) — standalone bin엔 node_modules 없음. client.ts:120의 import('@ladybugdb/core')가 동봉 .node를 못 찾음. (a) Formula wrapper NODE_PATH 주입(코드 무수정, 권고) vs (b) client.ts를 SPYGLASS_GRAPH_NATIVE_ROOT에서 로드. electron extraResources 패턴 이식.
  2. x64 prebuilt 확보(D2·D4) — 로컬엔 arm64 prebuilt만. release matrix x64 runner가 @ladybugdb/core-darwin-x64 확보해야 x64 tarball 동봉 가능.
  3. GRAPH_MODE 기본값(D2) — off → shadow 승격. native 동봉 후 회로차단기 폴백이 사용자 영향 0 보장하는지 검증.
  4. React web 빌드 접합(D2·D6) — 현재 packages/web → React 완료 시 Vite dist/. 동봉 경로 계약만 고정, 전환은 React 트랙 머지 후.
  5. version SSoT(D1·D4) — Formula version·release tag·package.json·SPYGLASS_APP_VERSION 정합. update-formula.yml이 tag에서 일괄 주입.
