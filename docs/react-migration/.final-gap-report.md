## 2. 미결 Gap (휴먼 검증·후속 — 코드 완료, 검증/결정 대기)

### 2-1. 런타임 수동 verify (자동 게이트 사각)
React 진입 활성화(P4-10) 후 **브라우저+데몬(9999) 실행이 필요한 검증**은 SSR/단위로 불가:
- 3모드 전환(browse/metadocs/settings), SSE 라이브 스트림, 데이터 population, FOUC/lang 4종, tooltip/col-resize 재바인딩
- 체크리스트: `packages/web/docs/react-migration/.manual-verify-p4-10-entry-activation.md`

### 2-2. TurnRows 가상 스크롤 (P5-05 보류)
- 단일 턴 최대 4683행 병목 **실재**하나, react-window가 semantic `<table>`+col-resize+chip-jump에 비호환 = over-engineering → 보류.
- 저위험 대안(점진 렌더/IntersectionObserver) 권고: `.perf-vscroll-decision.md` §5.

### 2-3. i18n classic 3종 (.js 잔존)
- `i18n.js`/`i18n-dom.js`/`lang-switcher.js`는 `window.I18n` 전역 island로 유지(P1-03 결정). 별도 i18n ESM 트랙에서 IIFE 엔트리 전환 시 제거.
- lang-switcher 시각 배치(React Chart 헤더 편입)는 chrome 후속.

### 2-4. electron 패키징 실기기 verify (P4-08)
- electron-builder `from:../web/dist` 전환 완료, 풀 DMG 빌드+3모드 로드는 macOS 서명 환경 의존 → 데스크톱 트랙 실기기 검증.
