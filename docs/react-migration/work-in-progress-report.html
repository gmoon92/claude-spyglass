⚠ 핵심 제약 — "전부 한 단위" (부분 전환 금지)

anomaly 배지 4종(bloatedSys·contextSaturation·agentSpike·turnSpike)은 모두 render/badges.ts의 private 헬퍼 anomalyStage(x)/anomalyNum(x, ...keys)를 공유합니다. 일부만 React화하면 이 헬퍼를 두고 (a) assets→src 역방향 import(아키텍처 위반) 또는 (b) SSoT 이중화(헬퍼 복제 → 서버 컨트랙트 변경 시 불일치 버그)가 발생합니다. 따라서 anomaly 배지 4종 + 공유 헬퍼는 한 번에 옮겨야 합니다. toolStatusBadge(payload 파싱, getToolResponse/nonEmptyStr/numVar 공유)도 같은 이유로 toolResponseHint와 묶입니다.
