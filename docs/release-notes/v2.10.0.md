## Highlights

메타 문서 간 호출 인과를 *시간 순서* 로 보여주는 **Sequential Flow Chart 모드** 가 새로 추가됐습니다. 기존 ego-graph(통계형 방사형) 와 토글로 전환되며, 사용자 선택은 localStorage 에 영속됩니다.

내부적으로는 **Kuzu (embedded graph DB)** 기반 `storage-graph` 패키지를 신설하고, SQLite 와 graph DB 사이의 dual-path adapter 를 도입했습니다. graph DB 가 비활성/실패해도 SQLite fallback 으로 사용자 경험에는 회귀가 없습니다.

## 주요 변경

### 신규 — Sequential Flow 모드
- 위→아래 인과 흐름의 순서도 시각화 (`meta-docs-flow-sequential.js`)
- 4단계 알고리즘 — center seed → PARENT_OF traversal → turn-after → 위상 정렬 (Kahn)
- API: `GET /api/graph/sequential-flow?center_kind=&center_name=&depth=`
- 카드 SSoT 통일: ego 모드와 동일한 `.icon/.body/.title-row/.sub/.ds-chip` 마크업
- MCP 서버 그룹핑(`subRows`) + HOT pill 카드 표면 동일
- 긴 이름 wrap (`is-wrapped`, NODE_MAX_W=260) + `resizeNodeToContent` 자연 폭 측정
- 4면 앵커(top/right/bottom/left) + 외곽 offset 으로 화살표 marker 가림 해소
- sub-row 클릭 → 도구 풀네임을 새 center 로 재로드

### 신규 — `storage-graph` 패키지 (Kuzu)

- Circuit Breaker + Mode Flag (`off` / `shadow` / `primary`)
- Sync Worker — `events_outbox` → Kuzu projection 비동기 전파
- DDL/schema apply, native binding lazy import

## DB / 마이그레이션

본 릴리즈는 **SQLite 와 Kuzu 둘 다** 데이터 변경이 있습니다.

- **SQLite Migration 049 — `kuzu_outbox`** — graph projection 비동기 동기화용 outbox 테이블. 서버 첫 시작 시 자동 적용됩니다. 다운그레이드 없이 안전.
- **Kuzu (graph DB)** — `~/.spyglass/graph/` 아래 새로 생성됩니다. 비어 있다면 sync worker 가 SQLite 의 기존 데이터를 점진적으로 projection. 별도 명령어 없이 자동.

> ℹ️ Kuzu 가 설치되지 않은 환경에서는 graph 기능이 `mode=off` 로 자동 폴백되고 기존 ego 모드는 정상 동작합니다. graph DB 설치는 후속 패치에서 웹 대시보드 *설정 패널* 로 안내될 예정.
